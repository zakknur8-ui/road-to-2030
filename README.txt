ROAD TO 2030 — PWA starter

Isi folder:
- index.html: aplikasi
- manifest.json: metadata instalasi
- sw.js: cache offline sederhana

Cara memasang di Android (perlu hosting HTTPS):
1. Buat akun GitHub jika belum punya, lalu buat repository baru bernama road-to-2030.
2. Upload tiga file ini ke root repository.
3. Buka repository > Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch; pilih branch main dan folder /(root), lalu Save.
5. Tunggu URL GitHub Pages muncul (format umumnya https://USERNAME.github.io/road-to-2030/).
6. Buka URL tersebut di Chrome pada Android, menu ⋮ > Add to Home screen / Install app.

Data aplikasi disimpan pada localStorage browser perangkat. Gunakan tombol Unduh cadangan data di tab Jurnal secara berkala. Menghapus data situs/browser dapat menghapus data aplikasi. Simpan file backup JSON di tempat aman.

Catatan: ini aplikasi pribadi lokal, belum dipublikasikan ke Play Store. Jangan masukkan informasi yang sangat sensitif.
